Название: Админ может создать нового пользователя

Предварительные действия:
1. Выполнить авторизацию под админом

Шаги:
1. В блоке Create New User ввести корректные username и password нового пользователя
2. Нажать кнопку Add User

Ожидаемый результат:
1. Отображается алерт, что пользователь создан
2. Новый пользователь отображается в списке All Users
3. Пользователь присутствует в БД

--------------------------------------------------------------------------------

Название: Админ не может создать нового пользователя с некорректными данными

Предварительные действия:
1. Выполнить авторизацию под админом

Шаги:
1. В блоке Create New User ввести некорректные username и password нового пользователя
2. Нажать кнопку Add User

Ожидаемый результат:
1. Отображается алерт, что пользователь не создан
2. Новый пользователь не отображается в списке All Users
3. Отображается сообщение об ошибке
4. Пользователь отсутствует в БД

--------------------------------------------------------------------------------

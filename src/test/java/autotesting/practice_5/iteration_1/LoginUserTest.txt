Название: Админ может залогиниться с корректными данными

Шаги:
1. Ввести корректные username и password
2. Нажать кнопку Login

1. Выполнен переход на страницу Admin Dashboard
2. Токен админа находится в Local Storage

Название: Пользователь может залогиниться с корректными данными

Шаги:
1. Ввести корректные username и password
2. Нажать кнопку Login

Ожидаемый результат:
1. Выполнен переход на страницу User Dashboard
2. Имя пользователя отображается на странице
3. Токен пользователя находится в Local Storage

--------------------------------------------------------------------------------

Название: Админ не может залогиниться с некорректными данными

Шаги:
1. Ввести некорректные username и password
2. Нажать кнопку Login

Ожидаемый результат:
1. Отображается алерт с сообщением об ошибке
2. Токен админа отсутствует в Local Storage

--------------------------------------------------------------------------------

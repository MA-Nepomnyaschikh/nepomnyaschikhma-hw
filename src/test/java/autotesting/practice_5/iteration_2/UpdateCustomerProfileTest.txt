Название: Пользователь может изменить имя в профиле

Предварительные действия:
1. Создать нового пользователя под админом
2. Авторизоваться под новым пользователем

Шаги:
1. Перейти в профиль пользователя
2. В поле Name ввести новое валидное имя
3. Нажать кнопку Save Changes

Ожидаемый результат:
1. Отображается алерт, что имя измененено
2. В профиле отображается новое имя пользователя
3. Профиль пользователя изменен в БД

--------------------------------------------------------------------------------

Название: Пользователь не может изменить имя в профиле на невалидное

(Валидация имени выполняется на бэке, поэтому достаточно проверки одного любого невалидного значения)

Предварительные действия:
1. Создать нового пользователя под админом
2. Авторизоваться под новым пользователем

Шаги:
1. Перейти в профиль пользователя
2. В поле Name ввести невалидное имя, например "Mikhail1"
3. Нажать кнопку Save Changes

Ожидаемый результат:
1. Отображается алерт, что имя не измененено с сообщением об ошибке
2. Имя пользователя не изменилось
3. Профиль пользователя не изменен в БД

--------------------------------------------------------------------------------

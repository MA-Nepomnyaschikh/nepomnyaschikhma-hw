Название: Пользователь может пополнить свой счет

Предварительные действия:
1. Создать нового пользователя под админом
2. Авторизоваться под новым пользователем
3. Создать счет

Шаги:
1. Нажать кнопку Deposit Money
2. В поле Select Account выбрать счет из предусловия
3. В поле Enter Amount ввести рандомную валидную сумму
4. Нажать кнопку Deposit

Ожидаемый результат:
1. Алерт, что пополнение выполнено
2. Баланс счета из предусловий в БД изменился
2. Соответствующая транзакция пополнения для счета из предусловий присутствует в БД

--------------------------------------------------------------------------------

Название: Пользователь не может пополнить свой счет невалидной суммой
(В операции Deposit для поля Amount валидация выполняется на фронте, поэтому понадобится параметризованный тест с параметрами: -0.01/0/5000,01)

Предварительные действия:
1. Создать нового пользователя под админом
2. Авторизоваться под новым пользователем
3. Создать счет

Шаги:
1. Нажать кнопку Deposit Money
2. В поле Select Account выбрать счет из предусловия
3. В поле Enter Amount ввести невалидную сумму (-0.01/0/5000,01)
3. Нажать кнопку Deposit

Ожидаемый результат:
1. Алерт с сообщением о невалидной сумме пополнения
2. Баланс счета из предусловий не изменился
3. Транзакции пополнения для счета из предусловий отсутствуют

--------------------------------------------------------------------------------

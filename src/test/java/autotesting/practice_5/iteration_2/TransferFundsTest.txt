Название: Пользователь может выполнить перевод средств между своими счетами

Предварительные действия:
1. Создать нового пользователя под админом
2. Авторизоваться под новым пользователем
3. Создать первый счет
4. Создать второй счет
5. Пополнить первый счет на сумму 10000

Шаги:
1. Нажать кнопку Make a Transfer
2. В поле Select Account выбрать первый счет из предусловия
3. В поле Recipient Account Number выбрать второй счет из предусловия
4. В поле Enter Amount ввести рандомную валидную сумму
5. Установить чек-бокс Confirm details are correct
6. Нажать кнопку Send Transfer

Ожидаемый результат:
1. Отображается алерт, что перевод выполнен
2. Баланс первого и второго счетов изменился
3. Соответствующие транзакции перевода и получения средств для счетов из предусловий присутствуют в БД
